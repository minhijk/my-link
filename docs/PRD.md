# [PRD] 마이링크 (MyLink) — 링크트리 클론 서비스 제품 기능 정의서

---

## 1. 프로젝트 개요 (Overview)

### 1.1 서비스 소개
- **서비스명**: 마이링크 (MyLink)
- **개념**: 여러 개의 웹 링크, SNS 채널, 포트폴리오를 하나의 프로필 링크로 통합하여 공유할 수 있는 **링크트리(Linktree) 클론 서비스**
- **디자인 철학**: 정갈하고 신뢰감 높은 **토스 디자인 시스템(TDS)**을 기본으로 하여 직관적이고 미려한 UI 제공
- **시연 목적 및 접근 방식**:
  - 현재 프로젝트는 단계별(Phased) 라이브 시연을 목표로 합니다.
  - **1단계(Phase 1)**에서는 대시보드나 통계 기능 등 복잡한 관리자 영역을 제외하고, **브라우저 로컬 스토리지(LocalStorage)를 활용한 프로필 페이지 렌더링에만 집중**하여 빌드합니다.

## 3. 사용자 시나리오 (User Scenarios)

### 3.1 주요 페르소나 (Key Personas)

1. **페르소나 A: 크리에이터 / 개발자 '이민혁' (프로필 개설자 / 관리자)**
   - **배경**: GitHub, 기술 블로그, 포트폴리오, SNS 등 다양한 활동 채널을 가지고 있음.
   - **목표**: 복잡한 웹 호스팅 설정 없이 단 1개의 주소로 자신의 디지털 프로필을 깔끔하게 공유하고 싶어 함.
   - **선호 스타일**: 군더더기 없는 토스 디자인 시스템(TDS) 특유의 신뢰감 있고 모던한 인터페이스를 선호함.

2. **페르소나 B: SNS 팔로워 / 채용 담당자 '김지은' (프로필 방문자 / End-User)**
   - **배경**: 인스타그램 바이오 또는 이력서에 첨부된 링크(`mylink`)를 모바일 스마트폰으로 클릭하여 접속함.
   - **목표**: 로딩 지연이나 어색한 레이아웃 없이 원하는 정보(포트폴리오, SNS, 최신 글)를 빠르게 확인하고 이동하고자 함.

3. **페르소나 C: 라이브 시연자 (Presenter / Demonstrator)**
   - **배경**: 라이브 코딩 및 데모 시연 자리에서 청중에게 프로덕트의 발전 과정을 단계별로 시연함.
   - **목표**: 복잡한 백엔드 설정이나 로그인 과정 없이, 브라우저 로컬 스토리지만으로 완성도 높은 프로필 화면과 데이터 영구성이 동작함을 직관적으로 보여주고자 함.

### 3.2 단계별 사용자 여정 (End-to-End User Journeys)

#### [시나리오 1] 방문자의 모바일 프로필 탐색 및 링크 이동 (★ Phase 1 핵심)
```
[방문자 링크 클릭] ➔ [프로필 페이지 로드] ➔ [소개 & 소셜 확인] ➔ [링크 카드 탭] ➔ [외부 사이트 새 탭 이동]
```
1. **페이지 진입**: 방문자(김지은)가 모바일 기기에서 마이링크 프로필 주소로 접속합니다.
2. **첫인상 및 정체성 확인**: 
   - 화면 상단의 둥근 프로필 아바타, 표시 이름(`이민혁`), 그리고 한 줄 소개글을 통해 개설자의 정체성을 1초 만에 인지합니다.
   - 상단에 배치된 소셜 아이콘 바(GitHub, Instagram, Email)를 확인합니다.
3. **링크 탐색 및 터치 인터랙션**:
   - 세로로 정갈하게 나열된 링크 카드 목록(포트폴리오, 기술 블로그, 오픈소스 등)을 탐색합니다.
   - 카드를 손가락으로 누르는 순간 TDS 특유의 섬세한 탭 피드백(미세한 눌림 및 그림자 효과)을 경험합니다.
4. **목적지 이동**: 카드를 탭하면 외부 웹사이트가 안전하게 새 창(`target="_blank"`)으로 열려 콘텐츠를 소비합니다.

---

#### [시나리오 2] 라이브 시연자의 로컬 스토리지 데이터 영구성 시연 (★ Phase 1 핵심)
```
[데모 페이지 접속] ➔ [TDS 프로필 렌더링 확인] ➔ [개발자도구 LocalStorage 검증] ➔ [새로고침 후 데이터 유지 증명]
```
1. **초기 로드 및 데모 데이터 검증**:
   - 시연자가 브라우저를 열면 별도의 백엔드 API 호출 없이도 로컬 스토리지에 저장된 기본 데모 프로필과 링크 카드들이 0.1초 만에 깔끔하게 렌더링됩니다.
2. **로컬 스토리지 영구화 확인**:
   - 브라우저 개발자 도구(F12)의 Application > Local Storage 탭을 열어 `mylink-storage` 키 안에 사용자의 프로필(`username`, `displayName`, `bio`)과 `links` 배열이 정형화된 JSON 형태로 보관되어 있음을 청중에게 보여줍니다.
3. **새로고침 및 무결성 증명**:
   - 페이지를 강력 새로고침(Ctrl+F5)하거나 탭을 닫았다 다시 열어도 하이드레이션 오류(Hydration Mismatch) 없이 기존 데이터가 온전히 복원되는 안정성을 시연합니다.

---

#### [시나리오 3] 크리에이터의 링크 관리 및 실시간 프리뷰 (Phase 2 예정)
```
[대시보드(/admin) 접속] ➔ [링크 추가 및 순서 변경] ➔ [우측 모바일 폰 실시간 확인] ➔ [내 링크 복사]
```
1. **관리자 진입**: 개설자(이민혁)가 `/admin` 대시보드에 접속합니다.
2. **콘텐츠 수정 및 실시간 피드백**:
   - 좌측 편집 패널에서 '새 링크 추가' 버튼을 눌러 새 블로그 글 제목과 URL을 입력합니다.
   - 우측에 위치한 가상 모바일 기기(iPhone 형태 목업) 화면에 타이핑 즉시 새 링크 카드가 렌더링되는 무지연 실시간 동기화를 체감합니다.
3. **링크 재배치 및 노출 토글**:
   - 위/아래 이동 버튼을 통해 가장 중요한 포트폴리오 링크를 최상단으로 재배치합니다.
   - 일시적으로 비공개하고 싶은 링크는 토글 스위치를 꺼서 즉시 숨깁니다.
4. **링크 공유**: 상단의 "내 링크 복사" 버튼을 탭하여 토스트 알림과 함께 클립보드에 복사하고 인스타그램 바이오에 붙여넣습니다.

---

#### [시나리오 4] 성과 분석 및 테마 브랜딩 커스터마이징 (Phase 3 예정)
```
[통계 탭 진입] ➔ [조회수 및 클릭수 분석] ➔ [테마 탭 진입] ➔ [1클릭 테마 전환]
```
1. **유입 통계 확인**:
   - 개설자가 대시보드의 `[통계]` 탭으로 이동하여 최근 누적 페이지뷰와 링크별 클릭수를 확인합니다.
   - 어떤 링크의 CTR(클릭률)이 가장 높은지 한눈에 파악하여 다음 콘텐츠 계획에 반영합니다.
2. **원클릭 테마 변경**:
   - `[테마]` 탭에서 기본 'TDS 토스 블루' 외에 '클린 다크'나 톡톡 튀는 '네오브루탈리즘' 테마를 클릭합니다.
   - 클릭 1번으로 배경색, 카드 보더, 폰트 스타일, 버튼 디자인이 완전히 새로운 분위기로 즉시 전환됩니다.

### 3.3 예외 상황 및 엣지 케이스 처리 (Edge Cases)

| 상황 (Edge Case) | 예상되는 문제 | 시스템 대응 및 처리 방안 |
| :--- | :--- | :--- |
| **LocalStorage 비어있음** | 사용자가 처음 접속했거나 캐시를 지운 경우 빈 화면 노출 | 스토어가 비어있을 경우 **기본 시연용 Mock Data를 자동 주입**하여 항상 완성된 화면 제공 |
| **모바일 초소형 기기 접속** | 가로 폭 320px(iPhone SE 등)에서 긴 제목이 찌그러짐 | 텍스트 줄바꿈(`break-words`) 및 최대 너비 자동 계산, 터치 영역 44px 이상 확보 |
| **잘못된 URL 형식** | `http://` 또는 `https://` 누락 | 링크 이동 시 프로토콜 자동 보정 및 안전한 외부 새 탭 처리(`noopener noreferrer`) |
| **SSR / CSR 불일치** | LocalStorage 로드 시점 차이로 React Hydration Warning 발생 | Zustand `persist` 하이드레이션 완료 플래그(`hasHydrated`)를 확인 후 화면 렌더링 |

## 4. Phase 1 상세 요구사항 (Current Scope)

### 4.1 프로필 페이지 화면 구성
1. **프로필 영역 (Profile Header)**:
   - 프로필 아바타 (이미지 URL 또는 기본 이니셜 아바타)
   - 표시 이름 (Display Name, 예: `이민혁`)
   - 핸들 텍스트 (`@username`)
   - 한 줄 소개글 (Bio, 예: `디지털 프로덕트를 만드는 개발자입니다.`)
2. **소셜 링크 바 (Social Icons)**:
   - 등록된 SNS 링크(GitHub, Instagram, Email, X 등)를 상단에 직관적인 아이콘으로 노출
3. **링크 카드 목록 (Link Cards)**:
   - 사용자가 등록한 활성화된 링크들을 세로 스택 카드로 렌더링
   - 카드 클릭 시 외부 새 탭(`target="_blank" rel="noopener noreferrer"`)으로 이동
   - TDS 스타일의 클린한 보더와 호버/탭 인터랙션 효과 적용
4. **푸터 (Footer)**:
   - 심플한 서비스 브랜딩 (`마이링크로 나만의 프로필을 만들어보세요`)

### 4.2 로컬 스토리지(LocalStorage) 연동 규칙
- 브라우저의 `localStorage`에 `mylink-storage` 키로 프로필 및 링크 데이터를 영구 저장
- 사용자가 페이지를 새로고침하거나 재접속해도 데이터가 그대로 유지
- 저장된 데이터가 없는 경우를 대비한 **완성도 높은 기본 데모 데이터(Mock Data)** 내장
- Next.js SSR과의 하이드레이션 불일치(Hydration Mismatch)를 방지하기 위해 클라이언트 로드 완료 후 렌더링 보장

## 5. Phase 1 데이터 모델 및 상태 관리 명세

### 5.1 Zustand 스토어 명세 (`useLinkStore`)

Phase 1에서는 복잡한 통계/편집 액션을 배제하고, **프로필 조회 및 로컬 스토리지 동기화에 필수적인 최소 스펙**으로 정의합니다.

```typescript
import { create } from 'zustand';
import { persist } from 'zustand/middleware';

// 1. 프로필 정보 모델
export interface UserProfile {
  username: string;       // 핸들 (예: 'minhijk')
  displayName: string;    // 표시 이름 (예: '이민혁')
  bio: string;            // 소개 문구
  avatarUrl?: string;     // 프로필 이미지 URL
  socials: {
    github?: string;
    instagram?: string;
    twitter?: string;
    email?: string;
  };
}

// 2. 링크 아이템 모델
export interface LinkItem {
  id: string;             // 고유 ID
  title: string;          // 링크 제목 (예: '개인 블로그')
  url: string;            // 목적지 URL (예: 'https://...')
  isActive: boolean;      // 활성화 여부
  order: number;          // 노출 순서
}

// 3. Phase 1 스토어 상태 구조
export interface LinkStoreState {
  // 상태 (State)
  profile: UserProfile;
  links: LinkItem[];

  // 초기화 및 데이터 복원 액션
  resetToDefault: () => void;
  setProfile: (profile: Partial<UserProfile>) => void;
  setLinks: (links: LinkItem[]) => void;
}
```

## 6. UI/UX 디자인 가이드라인 (TDS 기준)

- **컬러 팔레트**:
  - 배경: `grey-100` (`oklch(0.966 0.003 248)` / `#F2F4F6`)
  - 카드 표면: `white` (`#FFFFFF`)
  - 텍스트 주색상: `grey-900` (`oklch(0.237 0.020 258)` / `#191F28`)
  - 서브 텍스트: `grey-700` (`oklch(0.460 0.028 256)` / `#4E5968`)
  - 카드 보더: `grey-200` (`oklch(0.930 0.005 248)` / `#E5E8EB`)
  - 인터랙션 포인트: 토스 블루 `blue-500` (`#3182F6`)
- **타이포그래피**:
  - 표시 이름: Title-1 (18px, Bold)
  - 소개글: Body-1 (15px, Regular)
  - 링크 제목: Title-2 (17px, SemiBold)
- **카드 인터랙션**:
  - 기본: 깔끔한 1px 헤어라인 보더
  - 호버/터치: 살짝 위로 부유(`translate-y-[-2px]`), 섬세한 섀도우 효과, 우측 화살표 아이콘 전환
- **모바일 반응형 보장**:
  - 최대 너비 `max-w-md` (448px)의 중앙 집중형 레이아웃으로 모바일 기기 및 데스크톱 모두에서 일관된 앱 느낌 전달
